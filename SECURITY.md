--- Security ---
If you've found a security problem in PILK, please tell us privately, not in a public issue:
Here on GitHub: the Security tab, then Report a vulnerability. Only PILK's owner sees it.
Or by email: security@pilk.dev.
Please say which version of PILK you have (Settings, About), what you did and what happened. Don't send a password, a sign-in code or anything from your Minecraft account: PILK never needs them.
What happens next
You get a reply once it has been read, and we keep you told.
If it's real, the fix comes as a PILK update, signed like every update. PILK offers it the next time it starts, or straight away from Settings, Updates, "Check now".
When the fix is out, a security advisory here says what was wrong, which versions it affects and what to do. It credits you, if you'd like.
Please give us time to ship the fix before you make the problem public.
Which versions get fixes
Only the latest release. PILK updates itself, so restarting it is enough to get a fix.
